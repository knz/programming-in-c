# Programming in C

Course materials for the "Programming in C" component of the Datastructuren (Data Structures) course delivered at the University of Amsterdam in 2017.

## About

This repository contains lecture materials and programming assignments for teaching C programming with a focus on data structures and algorithms. The course is taught to:
- 1st year BSc Informatica (INF)
- 2nd year BSc Kunstmatige Intelligentie (KI)

## Materials

- Syllabus
- Assignments:

  1. **Reverse-Polish Notation** - Expression parsing and evaluation
  2. **mysort** - Insertion sort implementation
  3. **Binary trees and Huffman coding** - Tree structures and compression
  4. **Heaps and priority queues** - Heap data structures
  5. **Balanced trees and set operations** - Advanced tree structures
  6. **Bloom filters** - Probabilistic data structures

## Building

The course materials use reStructuredText and Markdown with HTML output. To build the documentation:

```bash
make
```

This will generate HTML and PDF versions of all assignments and syllabi.
